# Foundation 一致性测试

所有 Storage Provider 必须通过同一套一致性测试。测试不应只验证返回值，也要验证历史、事件、租户和并发语义。

## 必测类别

1. 对象创建、更新、软删除和版本递增；
2. 关系创建、基数约束、属性更新和终止；
3. 对象和关系历史快照；
4. 按版本、有效时间和记录时间查询；
5. 历史关系遍历；
6. 事务提交和回滚；
7. 乐观并发冲突；
8. 租户隔离；
9. 索引、分页和过滤；
10. Outbox 与审计原子写入；
11. 幂等批量操作；
12. Provider 能力声明和降级行为。

## 对象关系示例场景

使用 `Person`、`Organization`、`Assignment` 三类对象验证：

- 对象从组织甲调入组织乙；
- 查询当前归属得到组织乙；
- 查询调动前时间得到组织甲；
- 旧关系和新关系拥有不同 `link_id`；
- 对象变化和两条关系变化共享同一个事务和 Action；
- 任何租户不能读取其他租户的历史关系。
