# Java Foundry上游对齐修复计划

基线：Java ff944f7；上游v0.3.0 / 1d7e1aa。原则见ADR-0004。原v0.1任务清单不代表以下工作已完成。

## F1：通用读写治理

- [x] ODL保留Action权限，可信注册类型与manifest，默认拒绝未定义或未授权执行。
- [x] 对象参数按租户解析，验证类型、集合和未知参数；禁止客户端对象快照。
- [x] 当前/列表/历史读取统一字段白名单，GraphQL读取普通属性且不因隐藏属性报非空错误。
- [x] 内存幂等按租户/主体/动作隔离、请求摘要绑定、并发原子重放；回放重新验权。
- [ ] 持久幂等回执与业务事务同提交、跨进程并发和故障恢复。
- [ ] 读/写拒绝及敏感查看审计、字段隐藏元数据、授权后分页和执行快照的完整一致性验收。
- [x] OpenFGA Check路径/模型参数和租户编码修正，HTTP stub验证请求协议及失败拒绝。
- [ ] 真实OpenFGA/OIDC联调、模型及授权管理；不以stub代替集成验收。

## F2：事实完整性与时间

- [ ] 通用属性校验：必填、类型、枚举、未知属性、唯一、不可变；关系端点和并发基数。
- [x] 普通变更与删除断言、对象/关系effectiveAt重载及顺序迟到事实，旧格式历史明确隔离。
- [ ] 任意历史区间追溯更正及未来有效事实，物理提交时刻口径（如需）另立契约。
- [x] 格式2单查、列表和traverseAsOf在有效/记录时间上的一致行为；JDBC遍历一致快照。
- [ ] 旧业务历史有据迁移及大范围时间查询下推优化。
- [ ] memory、H2及目标关系库共享正反向并发测试。

## F3：ODL/Pack和API

- [ ] 完整AST或显式拒绝：enum/interface/link/computed/constraint/default等，禁止静默丢语义。
- [ ] 上游Library Pack在明确兼容范围内加载及执行借还；不支持的effects/sideEffects明确错误。
- [ ] 关系读取、类型化API、通用过滤/排序/聚合/分页计数及授权范围一致。
- [ ] 持久Schema Registry、破坏性变化分类、迁移与漂移门禁。

## F4：可靠同步、事件与交付

- [ ] 来源、字段血缘与冲突器实际接入同步；Checkpoint、重复乱序与恢复。
- [ ] Outbox领取/重试和消费幂等租约恢复；审计覆盖拒绝与成功路径。
- [ ] ObjectSet、计算属性、订阅、CLI/SDK、观测和部署按上游能力逐项评审实现。
- [ ] 实际国产库、OIDC/OpenFGA、性能与恢复验收。

FHIR/CDM领域适配与上游尚未实现的联邦/备份能力单独评估，不作为本轮核心重制的隐式要求。每个阶段记录运行证据和剩余项；不能用Mock/H2或测试数量替代实际集成验收。
