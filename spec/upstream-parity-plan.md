# Java Foundry上游对齐修复计划

基线：Java ff944f7；上游v0.3.0 / 1d7e1aa。原则见ADR-0004。原v0.1任务清单不代表以下工作已完成。

## F1：通用读写治理

- [x] ODL保留Action权限，可信注册类型与manifest，默认拒绝未定义或未授权执行。
- [x] 对象参数按租户解析，验证类型、集合和未知参数；禁止客户端对象快照。
- [x] 当前/列表/历史读取统一字段白名单，GraphQL读取普通属性且不因隐藏属性报非空错误。
- [x] 内存幂等按租户/主体/动作隔离、请求摘要绑定、并发原子重放；回放重新验权。
- [x] JDBC命令回执与业务同事务，H2文件恢复/跨Provider及两个独立JVM并发/提交前后强制退出验证；真实目标库仍单独验收。
- [ ] 读/写拒绝及敏感查看审计、字段隐藏元数据、授权后分页和执行快照的完整一致性验收。
- [x] OpenFGA Check路径/模型参数和租户编码修正，HTTP stub验证请求协议及失败拒绝。
- [ ] 真实OpenFGA/OIDC联调、模型及授权管理；不以stub代替集成验收。

## F2：事实完整性与时间

- [x] 通用属性校验：必填、类型、枚举、未知属性、唯一、不可变；对象/关系共享校验，数据库租户锁保证同Schema部署下的跨Provider竞争完整性。
- [x] 字面量默认值、readonly审计字段和字段/类型CEL约束；对象/关系共享执行。
- [ ] 任意引擎只读字段生成器、真实数据库并发/吞吐验收。
- [x] 普通变更与删除断言、对象/关系effectiveAt重载及顺序迟到事实，旧格式历史明确隔离。
- [ ] 任意历史区间追溯更正及未来有效事实，物理提交时刻口径（如需）另立契约。
- [x] 格式2单查、列表和traverseAsOf在有效/记录时间上的一致行为；JDBC遍历一致快照。
- [ ] 旧业务历史有据迁移及大范围时间查询下推优化。
- [ ] memory、H2及目标关系库共享正反向并发测试。

## F3：ODL/Pack和API

- [x] 单Schema普通接口继承、枚举和声明属性；GraphQL接口、枚举、列表及自定义标量输出。
- [ ] 完整AST及运行语义：跨Pack组合、computed、关系写入声明约束等，禁止静默丢语义。过渡期显式拒绝不支持项不能作为最终覆盖完成。
- [x] 未修改的上游ReturnBook本地动作：事务筛选删除ONE/ALL、完整匹配授权、旧目标重放验权、共享执行时间和简单表达式。
- [ ] 上游Library完整Pack加载及借还；事件/外部sideEffects及失败策略、补偿和恢复。明确拒绝不能视为覆盖完成。
- [x] 声明关系字段的双向导航、关系属性与已结束关系读取；GraphQL/REST共用权限及可见结果分页。
- [ ] 时间一致的关系API、关系写入声明约束、类型化Action API、通用过滤/排序/聚合/分页计数及授权范围一致。
- [ ] 持久Schema Registry、破坏性变化分类、迁移与漂移门禁。

## F4：可靠同步、事件与交付

- [ ] 来源、字段血缘与冲突器实际接入同步；Checkpoint、重复乱序与恢复。
- [x] Outbox领取/重试、消费完成回执及租约恢复；内存/H2和独立JVM中断验证。
- [ ] Action副作用任务及补偿、外部投递联调、死信与运维、回调自动续租；审计覆盖拒绝与成功路径。
- [ ] ObjectSet、计算属性、订阅、CLI/SDK、观测和部署按上游能力逐项评审实现。
- [ ] 实际国产库、OIDC/OpenFGA、性能与恢复验收。

完整覆盖以已固定的上游v0.3.0为基线，包括已实现的可选能力入口（FHIR/CDM等仍隔离为扩展，不在核心硬编码领域）。上游尚未实现的联邦/备份Provider不冒充其已有能力。每个阶段记录运行证据和剩余项；不能用Mock/H2或测试数量替代实际集成验收。
