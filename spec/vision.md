# Foundation v0.1 目标与验收

## 目标

实现一个可部署在国产关系数据库环境中的 Java 对象关系数据底座。它能够承载不同 Domain Pack，并统一提供对象、关系、当前状态、历史、授权、审计、事件和外部同步能力。

## 第一个验证场景

使用不包含具体业务规则的最小领域包：

```text
Person
Organization
Position
Assignment
```

验证人员从组织甲调入组织乙的完整生命周期：

1. 创建人员、组织、岗位和任职关系。
2. 查询当前人员归属和任职关系。
3. 执行调动 Action，终止旧关系并创建新关系。
4. 查询调动前的有效关系，结果仍为组织甲。
5. 查询调动后的有效关系，结果为组织乙。
6. 查看对象和关系历史，能够定位 Action、主体、来源和事务。
7. 订阅或消费状态变化事件。
8. 使用另一个租户访问时返回拒绝或空结果。

## 完成标准

- ODL、Action 和权限文件可被编译为统一运行时模型；
- 至少一个 JDBC Provider 通过 Foundation 一致性测试；
- 对象和关系的当前查询、历史查询、时间查询和遍历语义一致；
- 所有生产写入经过 Action 或同步命令；
- 对象、关系、历史、审计和 Outbox 事务一致；
- GraphQL 和 REST 读取共享同一授权和应用服务；
- 数据库方言不影响上层领域模型；
- 失败、并发冲突和权限拒绝有稳定错误码。

## 非目标

本版本不交付任何具体行业规则、内容库、渠道对接、AI助手或完整管理端。这些能力在底座验证完成后以独立 Domain Pack 和应用项目建设。
